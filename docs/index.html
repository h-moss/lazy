System Overview

This voice control system uses SpeechRecognition for microphone input, Whisper for transcription, and a local LLM to interpret commands into structured formats that can be executed by the pynput library.

Speech Recognition

Captures audio from the microphone and detects voice activity

Whisper Transcription

Converts spoken commands to text with high accuracy

LLM Interpretation

Processes text into structured command formats

Command Execution

Executes structured commands as keyboard and mouse inputs

Move Mouse Command

Voice Command:

"move mouse to 500, 300"

Transcription:

"move mouse to 500, 300"

Interpreted Command:

{
  "type": "mouse",
  "action": "move",
  "x": 500,
  "y": 300

System Architecture

Voice Control System Architecture

Components

  • SpeechRecognition: Handles microphone input and voice activity detection
  • Whisper: Transcribes audio to text with high accuracy
  • Local LLM: Interprets transcribed text into structured commands
  • Command Executor: Executes structured commands using pynput
